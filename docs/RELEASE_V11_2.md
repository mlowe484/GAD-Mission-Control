# V11.2 recorded 3D maneuver cinematic replay

Reuses all 4 published, source-qualified C3L-U/V/W Earth flights unchanged. Adds automatic stage-relative playback speed: 10 s first burn, 6.5 s subsequent burns, 7.5 s unpowered coast by default, manual fixed override available. Draws a 3D aperture wireframe during burns using stored K, phi, signed offset and transverse hint, reconstructing P6/3D drive-axis geometry. Does not recompute force or selected mass. No changes to 2D replay, Pilot or P6F archives.
