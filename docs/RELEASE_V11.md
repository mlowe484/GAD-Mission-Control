# Mission Control V11 — Pilot Challenge 2.0

Educational frontend release, not a new autonomous controller.

- Guided, Standard and Expert assistance, same GAD physics and same five scenario goals.
- Dashed approximate trajectory predicting the consequences of holding current engine controls fixed.
- Outcome-specific coaching, minimum altitude, peak K, powered time and illustrative scoring.
- Next-lesson navigation and current-session progress.
- Original single public entry at `index.html`; existing 2D replay evidence and 3D JPL reference unchanged.

Local headless Chromium desktop and phone tests covered scenario switching and resets, assistance toggling, and a deliberately failed surface-launch feedback report. Not all scenarios have been independently qualified for reachability.
